# 1.3.0 源码更新

本次从已有 GOAI 发布提交建立 `refs/heads/v1.3.0` 分支。旧 `refs/tags/v1.3.0` 标签、发布附件及线上部署保持原状。GitHub 分支入口显式使用 `/tree/refs/heads/v1.3.0`，避免与同名标签混淆。

## 更新范围

- 增加 `services/feature-drift-runtime`：隔离合成数据上的真实 CSV 回填、12 次 CPU 训练、持出集评估、路由切换、独立采样和回滚。
- AgentTeams Adapter 更新为 `1.3.0-live.5`，在授权范围检查后准备事件运行环境；驻场服务增加限定工作空间和事件的证据读取。
- 企业群呈现绑定角色的协作消息与来源，支持员工 @ 选择。
- 人工审批支持多条通知、紧凑弹窗和会话切换后的过期结果隔离。
- Live 计划在灰度与全量提升后绑定父部署实际版本，完整发布后补偿预期版本为 44，回滚后为 45。
