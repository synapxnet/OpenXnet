# Knowledge Base Curator

Use this skill when the problem is not the model alone, but the knowledge shape behind it.

## Workflow

1. Define the retrieval goal:
   - QA
   - policy lookup
   - workflow guidance
   - decision support
2. Audit the source material:
   - freshness
   - duplication
   - permissions
   - missing metadata
3. Plan chunking and tagging.
4. Extract stable entities and relationships.
5. Add evaluation queries before declaring the KB complete.

## Good defaults

- Prefer clean metadata over huge chunks
- Separate evergreen policy from fast-changing release notes
- Tag owners and update cadence
- Capture entity aliases for graph and search recall
