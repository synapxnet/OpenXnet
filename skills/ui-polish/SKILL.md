# UI Polish

Use this skill for practical product UI cleanup, not abstract design commentary.

## Workflow

1. Identify the primary user task on the screen.
2. Mark visual noise:
   - repeated controls
   - nested cards
   - broken alignment
   - inconsistent colors
3. Fix hierarchy in this order:
   - layout
   - spacing
   - typography
   - component emphasis
   - motion
4. Verify theme parity for light and dark modes.
5. Recheck empty states, dialogs, and hover states.

## Guardrails

- Reduce layers before adding decoration
- Keep chat input close to chat context
- Avoid duplicate navigation controls
- Make state changes legible without relying on color alone
